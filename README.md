# Virtual Assistant & Customer Support Portfolio

A responsive, multi-page portfolio for Matthew Austine, presenting virtual assistance, executive administrative support, and customer support skills.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `projects.html` — Projects and demonstrations
- `how-i-work.html` — Work process
- `contact.html` — Contact

## Publish with GitHub Pages
1. Upload all files and folders in this package to the root of your new GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait for the Pages deployment to finish and open the published URL.

## Personalize before sharing
- Replace the stock portrait in `index.html` with the user's seated portrait.
- Replace the portrait in `about.html` with the selected About Me portrait.
- Replace images in `how-i-work.html` with the presenting cartoon and preferred visuals if desired.
- Update contact details in `contact.html` if needed.
- Test all three demo links in `projects.html`. Demo links are provided as currently known and should be checked before sharing.

The website uses remote Unsplash images as initial visual placeholders. Internet access is needed to display those images and the Google Font. The contact form opens a prefilled email draft and does not store submissions.


## Personal images
Your selected images are included in the `images/` folder and linked locally from Home, About Me, and How I Work. Keep the `images/` folder when uploading the files to GitHub Pages.
